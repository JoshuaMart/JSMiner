JSMiner doit transformer un script fourni ou acquis dans un périmètre autorisé en un inventaire compact : endpoints, secrets potentiels, opérations GraphQL et sous-domaines observés. Les sources restent dans un stockage dédié, consultable module par module grâce à un `handle` opaque.

<CardGrid>
  <Card title="Un contrat compact" icon="document">
    `POST /analyze` retourne des résultats structurés et leur provenance. Aucun code source n’est inclus dans cette réponse.
  </Card>
  <Card title="Des traitements indépendants" icon="setting">
    Chaque outil dispose de son budget. Une transformation qui échoue laisse les résultats des autres traitements disponibles.
  </Card>
  <Card title="Des sources à la demande" icon="open-book">
    Le manifeste liste les modules ; une seconde requête lit un module ou une portion bornée de celui-ci.
  </Card>
  <Card title="Un cache reproductible" icon="puzzle">
    Le hash du script identifie les octets. Les versions, options et artefacts d’entrée identifient l’analyse.
  </Card>
</CardGrid>
