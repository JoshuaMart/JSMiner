JSMiner extrait des **endpoints, secrets potentiels, opérations GraphQL et sous-domaines**. Il retourne un JSON compact avec la provenance des observations et un `handle` pour consulter les sources séparément.

Le service privé utilise Node.js, SQLite et des workers Docker isolés. Il peut analyser du contenu fourni ou acquérir une URL autorisée, transformer les bundles et réutiliser les traitements en cache.
